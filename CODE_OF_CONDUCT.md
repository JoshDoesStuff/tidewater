# Code of conduct

This is a small hobby project. The rules are short.

## What I expect

- Be kind and assume good faith. People report bugs and ask for things because they care about the app.
- Stay on topic. Issues and pull requests are for Tidewater.
- Be specific and patient. Include the details asked for, and give me time to reply: this is done in spare time.
- Criticize code and ideas, not people.

## What isn't welcome

- Harassment, insults, slurs, or personal attacks of any kind
- Spam, advertising, or pushing unrelated projects
- Trolling, or repeatedly derailing a thread
- Sharing other people's private information (including passwords, API keys and private server addresses)

## What happens

I may edit or delete comments, close or lock issues and pull requests, and block people who break these rules,
without warning. To report a problem with someone's behavior, use GitHub's **Report content** menu on the
comment, or contact me through a private channel on my GitHub profile.
